## 🚀 Featured projects

### [CivicSignal](https://github.com/mishraasakshi/civicsignal) - AI campus complaint intelligence · [**Live demo**](https://civicsignal.wittycliff-03d73af7.eastasia.azurecontainerapps.io)
Students report campus problems in English, Hindi or Hinglish (*"tubelight khrb h"*); a multilingual NLP model
sorts them into categories and flags uncertain ones for a human, and supervisors see repeated problems with
AI-written summaries.
- Chose the model on **98 real student complaints**, not synthetic data: accuracy on genuine complaints **55% → 66%**
- DBSCAN grouping of repeated issues + LLM summaries (LangChain, Groq), validated with Pydantic
- FastAPI · PostgreSQL · React + TypeScript · Docker · **Azure Container Apps** · 99 automated tests in CI

### [Deep Packet Inspection Engine](https://github.com/mishraasakshi/Deep-Packet-Inspection) - C++
Multithreaded engine that parses Ethernet/IP/TCP/UDP traffic from PCAP files, identifies HTTPS domains via
**TLS SNI extraction**, tracks five-tuple flows and filters traffic by IP, domain and application.

### [Facial Emotion Detection & Eye Tracking](https://github.com/mishraasakshi/Face-Emotion-Detection-and-Eye-Tracking) - Python · team project
Real-time computer vision from a normal webcam using InsightFace (106-point landmarks) and the ONNX-based
HSEmotion model, with EMA smoothing, frame skipping and threaded capture for low latency.

### [Smart Price Finder](https://github.com/mishraasakshi/smart-price-finder) - Flask + JavaScript
Compares product prices across Amazon India and Flipkart and highlights the best deal.

### [Witty Groq Chatbot](https://github.com/mishraasakshi/Witty-Groq-Chatbot) - LangChain + Streamlit
LLM chatbot with a custom persona and session memory, using the Groq API.
